# Benfll Tap

## How do I install these formulae?

`brew install benfll/tap/<formula>`

Or `brew tap benfll/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "benfll/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
